# Xブロックチェッカー（サーバー側秘匿版）

- ブラウザ側はUIと `/api/check` 呼び出しだけ。
- 結果ページに大きな「ツイートする」と小さな「戻る」を配置し、どちらもXの投稿作成画面を開きます。
- Telegram Bot Token / Chat ID はHTML/JSに含めず、サーバー環境変数で管理。
- X取得・フォロワー数取得・決定的計算・Telegram送信はサーバー側。
- ブラウザ側コードは圧縮してあります。ソースマップはありません。
- Xのアクセス制限、ログイン要求、CAPTCHA等を回避しません。
- 公開HTMLからフォロワー数を確認できない場合はサーバーエラー。
- 表示値は実際のブロック情報ではなく、フォロワー数の0〜5%を上限とした決定的な計算値です。

## 起動
Node.js 18以上で `npm install` → `npm start`。
本番環境の環境変数 `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` を設定してください。

## 重要
ブラウザに送られるコードを完全に不可視にはできません。秘密情報と重要処理をサーバー側へ置くことで、開発者ツールから秘密情報が直接見えない構成にしています。
